# Rishabh Singh — Portfolio

A responsive personal portfolio for Data Engineering, Data Analytics and Data Science roles.

## Run locally
Open `index.html` in a browser.

## Deploy
Upload these files to a GitHub repository and enable GitHub Pages.

## Customize
- Update project GitHub links when individual repositories are ready.
- Add a PDF resume as `Rishabh_Singh_Resume.pdf` and add a Resume button if desired.
- Replace any project descriptions with final verified metrics.
